Database Architecture

The system connects to Supabase PostgreSQL over a secure SSL session using a ThreadedConnectionPool. Connections are automatically acquired and returned to the pool using RAII context managers (with get_connection() as conn:), guaranteeing zero connection leaks and preventing pool exhaustion across simultaneous camera streams and administrative requests.
